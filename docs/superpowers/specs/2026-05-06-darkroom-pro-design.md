# Darkroom Pro 设计规范

> AI 商品图生成小程序 · 前端视觉改版  
> 设计方向：专业影棚替代品 — 品牌电商/工作室  
> 日期：2026-05-06

---

## 一、设计核心理念

**"你在用一台专业设备，不是又一个手机 App"**

目标用户是品牌电商和拍摄工作室，他们熟悉专业工具（Capture One、Lightroom、DaVinci Resolve），对"暗房 → AI 生成"这个叙事有天然的认知基础。

三个设计原则：

1. **深色优先** — 专业图片工具几乎全是深色 UI，看图片时不刺眼，和白色商品图形成天然对比，让图片成为视觉焦点
2. **克制动效** — 3 处关键动效（登录光圈、生成扫描线、FAB 缩放），其余地方保持硬切换。专业工具需要"流畅的确定感"，不要轻浮的弹跳
3. **暖金唯一强调色** — 只有暖金色可以抢眼，其余全是灰色阶。避免多个颜色打架

## 二、色彩体系

### 灰度层级（从深到浅）

| 用途 | 色值 | 说明 |
|------|------|------|
| 页面底色 | `#0d0d0d` | 暗房最深处 |
| 卡片/面板背景 | `#1a1a1a` | 轻微浮现 |
| 悬浮态/输入框 | `#262626` | 可交互区域 |
| 分割线/边框 | `#333333` | 边界但不抢眼 |
| 禁用/辅助文本 | `#737373` | 最低存在感 |
| 次要文本 | `#a3a3a3` | 可读但后退 |
| 主文本 | `#f5f5f5` | 高对比度 |

### 暖金色强调（唯一颜色）

| 用途 | 色值 | 说明 |
|------|------|------|
| 主强调 | `#d4a853` | 像暗房安全灯/黄金时刻 |
| 悬停态 | `#e8c97a` | 稍亮 |
| 按下态 | `#b8923a` | 稍暗 |
| 光晕 shadow | `rgba(212, 168, 83, 0.25)` | 暖金色的"呼吸感" |

### 功能色（状态指示）

| 状态 | 色值 | 说明 |
|------|------|------|
| 成功/完成 | `#4ade80` | 绿色，保留现有逻辑 |
| 错误/删除 | `#f87171` | 红色，保留现有逻辑 |
| 进行中/警告 | `#fbbf24` | 琥珀 |


### CSS 变量定义（替换现有 app.wxss 主题变量）

```css
page {
  --bg-deep: #0d0d0d;
  --bg-card: #1a1a1a;
  --bg-input: #262626;
  --border-default: #333333;
  --border-accent: #d4a853;
  --text-primary: #f5f5f5;
  --text-secondary: #a3a3a3;
  --text-disabled: #737373;
  --accent: #d4a853;
  --accent-hover: #e8c97a;
  --accent-active: #b8923a;
  --accent-glow: rgba(212, 168, 83, 0.25);
  --success: #4ade80;
  --danger: #f87171;
  --warning: #fbbf24;
  --font-mono: "SF Mono", "Menlo", "Courier New", monospace;
}
```

**删除现有 light/dark 双主题**。这个产品不需要 dark mode toggle——它生来就是深色的。保持设计的一致性和简单性。

## 三、字体

小程序受限于微信内置字体，但可以通过字重和间距制造层次：

| 层级 | 字号 | 字重 | 字间距 | 用途 |
|------|------|------|--------|------|
| Display | 44rpx | 600 | 0.05em | 页面大标题 |
| Title | 32rpx | 600 | 0.02em | 卡片标题/面板标题 |
| Body | 28rpx | 400 | 0 | 正文/描述 |
| Caption | 24rpx | 400 | 0.01em | 辅助信息/状态标签 |
| Mono | 36rpx | 500 | 0 | 配额数字/倒计时 |

数字（配额、次数、价格）使用等宽字体栈 `"SF Mono", "Menlo", "Courier New", monospace`，增加"设备读数"的专业感。

```

│                          │
│                          │
│         ◉  ← 光圈呼吸    │
│       (暖金、缓慢缩放)    │
│                          │
│     AI 商品图生成         │

│   │   微信授权登录     │   │  ← #1a1a1a 底 + 暖金边框

│                          │

└──────────────────────────┘
```

**光圈动画**：
- CSS animation，4s 循环
- 缩放 0.95 → 1.05 → 0.95，叠加缓慢旋转
- 登录成功后收缩成点，页面切换
- 实现：小程序 `animation` 属性支持 keyframes

**登录按钮**：
- 背景 `#1a1a1a`，边框 2rpx solid `#d4a853`，文字 `#d4a853`
- hover 时 border-color 变 `#e8c97a`，加一个微弱的 `--accent-glow` box-shadow

## 五、动效规格

### 5.1 登录光圈

```css
@keyframes aperture-breath {
  0%, 100% { transform: scale(1) rotate(0deg); opacity: 0.8; }
  50%      { transform: scale(1.05) rotate(180deg); opacity: 1; }
}
/* 4s 循环，ease-in-out */
```

### 5.2 AI 生成扫描线

任务提交后，卡片内商品图上方出现一条 2rpx 的暖金色横线，从上到下扫描：

```css
@keyframes scan-line {
  0%   { top: 0; }
  100% { top: 100%; }
}
/* 1.5s 循环，ease-in-out */
```

完成后扫描线消失，结果图从暗到亮 fade in（模拟暗房显影）：

```css
@keyframes develop {
  0%   { opacity: 0; filter: brightness(0.3); }
  100% { opacity: 1; filter: brightness(1); }
}
/* 0.6s，ease-out */
```

### 5.3 FAB 按钮反馈

```css
@keyframes fab-press {
  0%   { transform: scale(1); }
  50%  { transform: scale(0.92); }
  100% { transform: scale(1); }
}
/* 0.3s，cubic-bezier(0.34, 1.56, 0.64, 1) — 弹性回弹 */
```

### 5.4 其余交互

- **卡片点击**：scale(0.98)，border-color 闪暖金 200ms
- **按钮点击**：背景色从 `--accent` 变 `--accent-active`，过渡 150ms
- **面板弹出**：translateY(100%) → translateY(0)，300ms ease-out
- **页面切换**：默认系统过渡，不自定义

## 六、加载态 & 骨架屏

### 骨架屏（任务列表首次加载）

3 张卡片轮廓：
- `#1a1a1a` 底 + `#262626` 的 shimmer pulse 动画
- 左方 block（模拟缩略图） + 右方 3 条横线（模拟文本行）

```css
@keyframes shimmer {
  0%   { background-position: -200% 0; }
  100% { background-position: 200% 0; }
}
.skeleton {
  background: linear-gradient(90deg, #1a1a1a 25%, #262626 50%, #1a1a1a 75%);
  background-size: 200% 100%;
  animation: shimmer 1.5s infinite;
}
```

### 图片上传中

上传区域从暖金虚线变成暖金实线 + 居中显示百分比数字（等宽字体）。

### 图片加载

占位区域 `#1a1a1a` + 暖金色 shimmer，加载完成后 fade in。

## 八、不做的事

- ❌ 不保留 light/dark 双主题切换 — 产品生来深色
- ❌ 不保留蓝色 `#1890ff` — 全部换成暖金 `#d4a853`
- ❌ 不加复杂动效 — 保持克制，只有 3 处关键动效
- ❌ 不添加新手引导/onboarding — 后续单独设计
- ❌ 不改动后端 API 和数据结构 — 纯前端视觉改版
